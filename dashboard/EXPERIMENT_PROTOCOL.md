# Smoke protocol, scientific safeguards and validation limits

## Scope

This is an end-to-end engineering smoke, not a confirmatory Q-SHIFT study. It checks that the dashboard can stream Stim samples, train and checkpoint two compact models, save paired validation/test evidence, score a frozen matching decoder, and persist actual counters. The experiment does not evaluate adaptive switching or establish that neural decoding is useful.

## Frozen smoke configuration and streams

- Stim rotated surface-code Z memory, distance 3, five rounds; 40 detectors, one observable.
- Balanced categorical Pauli regime; gate fault total `p=0.003` for 1Q and 2Q Pauli channels; measurement flip `p=0.003`; Pauli bias ratio 10 as provided by the archived generator.
- 8,000 training / 1,000 validation / 1,000 test; batch 256; learning rate 0.001; direct + residual MLP.
- Seed root 1,800,000,001; disjoint train, validation and test batch ranges with model RNG seed 1,870,000,001. The saved seed preflight checked 2,076 recoverable historical values and found no collision. This does not establish disjointness from unrecorded historical seeds.
- Frozen PyMatching selection from `outputs/phase2b_pauli_bias/CALIBRATION_SELECTION.json`; this run did not use the test labels to change the baseline or model.

Training batches are generated by Stim one mini-batch at a time and immediately used for optimization. A distinct validation stream is sampled before the optimization pass. The final test stream is not generated until after the last optimizer update. During evaluation all four prediction arrays are paired to the same detector rows and observable labels. Test labels are used only to calculate final scores after training. The dashboard exposes the configured simulator regime in run metadata, but the network receives only detector bits (and, for residual mode, the fixed decoder's prediction).

The test arrays and predictions, validation arrays and predictions, model checkpoint, configuration, seed inventory and metadata are retained under the run ID. Training rows are intentionally not stored to keep the process bounded. Consequently, the training shot count is supported by worker counters, seed allocation and checkpoint progress, not by a saved row-by-row training archive.

## Primary smoke records

Saved test outcomes were identity 52/1,000, fixed PyMatching 4/1,000, direct MLP 52/1,000, and PyMatching-residual 4/1,000. The direct-vs-fixed paired error difference is +0.048 absolute LER, with 50 direct-only failures and 2 fixed-only failures. Residual-vs-fixed has zero discordant prediction/error shots. The saved one-batch Wilson intervals and exact McNemar p-value are descriptive only; there are no independent seed-root replicates, no multiplicity-controlled comparisons, and no adaptation policy in this smoke.

The independent read-only verifier re-creates the circuit and DEM, checks source/config/evidence hashes, re-decodes validation and test detector arrays with the frozen PyMatching model, recomputes both neural predictors from the saved checkpoint, and compares the recomputed paired metrics with run metadata and SQLite. Its output is `dashboard/run_data/runs/69e013ce457946f28f0ceb6308f39647/independent_verification.json`; the associated SHA-256 file list is in `run_manifest.json`.

## Limits and next experiment

The smoke uses one root, one balanced noise condition, one distance, 1,000 final shots and a CPU-only PyTorch build. It cannot estimate generalization across roots/regimes, GPU throughput, model ranking stability or adaptive benefit. The direct network performed poorly here; the residual network made no changes. Preserve that negative observation.

Recommended next experiment: after installing and verifying a CUDA-enabled PyTorch build, run a development-only 20-root paired comparison at d=3/5 rounds, Z memory, balanced noise, with 100,000 training, 10,000 validation and 10,000 held-out test shots per independent root. Freeze the architecture and scoring rule before sampling, use the same test detector arrays for identity, PyMatching, direct and residual predictions, report seed-clustered intervals and shot-level discordances, and do not tune on the held-out test labels. This would test whether the smoke's poor direct result persists with more training while checking that the residual model adds value; it would still be development evidence, not adaptive superiority.
