# Architecture

```text
Browser (React + TypeScript + Tailwind)
  ├─ /api/research  → committed Stage 4B summary + independently recorded audit status
  ├─ /api/health    → validates local Stim/DEM/PyMatching graph dimensions
  ├─ /api/simulate  → synthetic Stim circuit
  │                    ├─ independent detector-only calibration
  │                    ├─ fixed nominal PyMatching
  │                    ├─ detector-profile-estimated PyMatching
  │                    ├─ privileged true-probability reference
  │                    └─ one paired evaluation detector/observable sample
  └─ /api/dataset/schema + latest returned records → live-only syndrome explorer
```

The FastAPI process binds to IPv4 loopback (`127.0.0.1`) and the middleware accepts only loopback clients; forwarded headers are ignored. Uvicorn is started with proxy-header processing disabled. Vite is used only for development and build. The production app is served locally by FastAPI from `webapp/dist`.

The live endpoint reuses the read-only, established Q-SHIFT circuit generator and Stage 4 profile estimator modules. It generates three profile batches at p={0, .01, .02}, a separate calibration batch, and one evaluation batch. Only calibration detector bits enter the estimator. Every decoder then receives the same evaluation detector rows. Observable labels are used only to score predictions. Simulation calls are bounded to 10,000 evaluation shots and 5,000 calibration shots.

The application reads the tracked Stage 4 results and audit JSON only. It does not search for, enumerate, or open sealed-test locations. Historical raw Stage 4B arrays are ignored by Git and are deliberately not copied into this worktree; the dataset explorer therefore presents live sample rows generated by the current browser session.
