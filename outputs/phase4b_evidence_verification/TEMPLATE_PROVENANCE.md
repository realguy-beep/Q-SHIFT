# Template provenance

The frozen protocol text says reuse Phase 4A templates. The actual runner samples nine template circuits with `template_per_grid_point=50000`, seeds 53000001 through 53000009, and writes a new `TEMPLATES.json`. RESULTS reports 450000 template shots. The Phase 4A template bank is not loaded. This is a documented protocol deviation: Phase 4B has an independently generated template bank.
