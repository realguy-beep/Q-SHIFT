# External project reconstruction

This is a source-and-paper reconstruction, not a reproduction run. No outside repository was cloned, built, installed or executed.

| Project | Decoder, input and learning/calibration | Evidence and strongest relevant baseline | Q-SHIFT transfer / blocker |
|---|---|---|---|
| **HAMLD** | Approximate ML from a detector-error hypergraph. The algorithm uses syndrome-guided hyperedge selection, probability truncation and tensor contraction approximations. No learned weights; needs a model/DEM. Public README example builds a Stim circuit, passes an undecomposed DEM (`decompose_errors=False`) and calls `decode_batch`. | 2026 paper: circuit-level data on surface/color/BB codes; d=3/r=3 surface case reports optimal accuracy. Comparisons include MWPM, Chromobius, BP+OSD and MLD/TN-MLD in selected small cells. | Best near-term hypothesis: the input format and current d=3 scale align, and the estimator/CNN line has not shown decoder gains. Must check if Q-SHIFT's DEM with nonzero burst and categorical `PAULI_CHANNEL_2` is accepted faithfully. Repo calls real-time requirements unmet; build has Bazel 8.2.1/C++ dependencies and README describes enabling pybind API by editing package init. Validate exact source revision/build and compare to a strong static PyMatching model before claiming utility. |
| **NVIDIA Ising surface predecoder** | Local spatiotemporal CNN predecoder predicts/cleans a majority of errors before a global decoder. Public repo supplies PyTorch + Stim inference and training recipes, a PyMatching path, configuration/benchmarks and a Stim-sample interface. Checkpoints (R=9/13) are separate, access-controlled Hugging Face artifacts. Training guidance says train at R and at least 67M shots/epoch with 8 GPUs; noise upscaling is enabled by default unless explicitly disabled. | Public paper is a preprint (2026) reporting speed/accuracy tradeoffs; repo includes Uncorr-PM and Corr-PM, with Corr-PM labeled best classical baseline. | Hybrid local correction plus global fallback is structurally different from Q-SHIFT's earlier global residual CNN. But Q-SHIFT is only d=3/r=5 with categorical channels and an injected common-cause burst. Public checkpoints train/evaluate at R>=9; available weights have access/license conditions. Do not port until exact geometry, noise mapping, model card/license, inference latency, and fairness versus matched Corr-PM are understood. |
| **AlphaQubit (AQ1)** | Recurrent state vectors per stabilizer; spatial conv layers and transformer attention update using the current round and accumulated state. Trained with simulated pretraining, then limited real-device fine-tuning; uses analog readout where present. | Nature 2024 compares on Sycamore d=3/5 experimental data and simulation through d=11, against correlated matching (including analog-augmented matching) and TN decoder. | Directly demonstrates value of long syndrome history and hardware-specific information; Q-SHIFT currently has discrete detectors from simulated 40-detector shots and no analog input. Training/data/code stack not publicly identified for faithful implementation. High complexity and poor first study fit. |
| **AlphaQubit 2** | Streaming recurrent plus spatial transformer; persistent state carries syndrome history. Paper describes causal per-cycle updates, fixed-cost streaming and one-model use except select high-distance/experimental ensembles. | 2025/26 arXiv paper reports near-MLD surface/color performance up to d=23, d=11 real-time accelerator throughput, robustness to a 16-fold noise range and million-cycle tests. Preprint evidence, hardware and system scale differ from Q-SHIFT. | Best architectural inspiration for causal temporal state, not a drop-in small decoder. No inspected public implementation. Would require new model/training/data pipeline and careful comparisons against streaming classical decoders. |
| **Tensor-network decoder** | Approximate contractions calculate posterior/correction information over code spacetime; no supervised training. The 2024 method develops higher-dimensional contraction techniques for noisy measurements and circuit-level models. | Reports better accuracy than matching on rotated surface code circuit-level noise and high-accuracy results for 3D sectors. Public `tndecoder3d` repository. | Valuable small-instance reference for decoder headroom. Contraction bond/truncation choices affect accuracy and runtime; near-optimal d=3 results do not establish deployability or ability to adapt online. |
| **Astra (GNN message passing)** | Learns message-passing on a Tanner graph, with syndrome-constraint losses; trainable on QLDPC Tanner graphs. Astra+OSD reduces fallback calls. | 2025 npj QI; surface/BB QLDPC evaluations, including distance extrapolation against BP+OSD; the paper's QLDPC/code-capacity scope is not identical to Q-SHIFT circuit level. | Attractive when code family moves toward QLDPC. Today, graph extraction, time/measurement expansion, and explicit X/Z joint correlations are unresolved for this repository's detector model; public source exists but not a first choice. |
| **BP+OSD / BP+LSD** | BP estimates error distributions; OSD solves a reprocessing problem on selected low-reliability bits. LSD performs localized statistics decoding on error clusters. No learned model required. | Strong QLDPC benchmarks; public `ldpc` implementation. | Useful diagnostic alternative, but surface-code matching is a stronger and more natural incumbent. OSD's latency tail and code-family suitability need measurement; not top three for the current target. |

## Interpretation

The external “beat PyMatching” claims are conditional on their own specific decoder flavor, noise, code and compute setting. HAMLD is potentially the closest to Q-SHIFT's current small surface circuit; Ising and AlphaQubit are evidence that local hybrid and streaming learned designs can work when trained and benchmarked at suitable scale; tensor networks are a plausible offline oracle. None establishes a Q-SHIFT improvement. The local recommendation is **reproduce a released baseline first**, isolate its modeling assumptions, then consider an adaptive extension only if static utility headroom is visible.
