# NS-4A Research Direction Decision Matrix

This compares the already proposed V2 study with a separate future adaptive decoder-selection study. It does not change either protocol or authorize experiments.

| Dimension | A. NS-4A V2: BeliefMatching vs pooled-fixed PyMatching | B. Future adaptive decoder selection under changing noise |
|---|---|---|
| Scientific question | On a finite set of categorical Pauli and synthetic spatial-burst conditions, does BM change paired LER relative to one globally calibration-selected static PM decoder when both use the same selected DEM? | Can a causal policy select or update decoders during stationary, abruptly changing, or gradually drifting noise and improve over strong pooled-fixed and equally informed periodic recalibration? |
| Current evidence | Deterministic compatibility and interface evidence; a small detector-only V6 engineering benchmark. No V2 logical-error evidence. | Previous classifier/switch and online-weight directions did not establish utility. No current V2 evidence supports an adaptive gain. |
| Data / information parity | V2 pairs the same evaluation detector/observable samples across arms and provides BM and primary PM the same selected DEM and model provenance. The selection labels are separate and confined to choosing one global fixed PM configuration. | Requires detector-only causal calibration histories, strictly pre-block inputs, identical paired evaluation batches, and matched history/compute budgets for static, periodic and adaptive policies. |
| Baseline strength | Strong within the 12 prespecified DEM-family × PM-mode grid, but not globally optimal across all possible weights/models. Selection rank stability is important. | Must include the same pooled-fixed PM, a periodic recalibration control with comparable resources, and preferably an offline privileged oracle clearly marked nondeployable. |
| Novelty / likely contribution | Potentially a bounded empirical comparison of a particular correlation-aware decoder with calibrated strong matching on a synthetic finite grid. The contribution is narrow and negative/null outcomes may still be useful if integrity is clear. No broad novelty claim is established here. | Potentially more interesting if causal utility beyond stronger static calibration is demonstrated under defined drift. Adaptive decoding/calibration is established research territory, so novelty must be located in the exact estimator, trigger, noise process, fairness and failure envelope. |
| Main limitations | Ten evaluation roots/cell, no evidence-based power, no practical effect threshold, nonfactorial cells, approximate DEM, synthetic burst, and unresolved historical exposure influence. | New estimator/policy and noise-transition design needed; substantial leakage risk (future samples, hidden regime labels, logical outcomes); easy to mistake oracle or periodic calibration for deployable online adaptation. |
| Publication path | First resolve evidence boundary and execution feasibility. If authorized and completed, report as exploratory finite-grid feasibility, not confirmation or general decoder superiority. | Separate hypothesis, protocol and freeze after development evidence; no automatic expansion from V2. Requires independent roots and prospectively frozen drift/no-drift controls. |
| Recommendation | **Retain as a candidate exploratory feasibility study, but do not authorize execution until corrections are closed.** | **Keep separate and future-facing.** Do not retrofit adaptation language into V2 or infer its success from V2. |

## Decision

Path A is the nearer-term and better bounded question. It tests decoder algorithm behavior with matched assumed-model information; it does not estimate a noise parameter, switch models by condition, respond to drift, or show an online controller. A negative result would still bound this particular BM/DEM combination. A positive exploratory result would motivate, but not establish, a larger independently designed comparison.

Path B asks a different systems question and needs a distinct experimental architecture. To be credible it would need block-level schedule definitions, stationary controls, abrupt and gradual drift, detector-only causal change detection, calibration latency and uncertainty, matched periodic recalibration, a strong fixed comparator, and an independent test stream. It also needs explicit adaptation versus static-selection hypotheses and leakage tests. No current evidence justifies initiating it within the V2 workload.

The Phase 4C native rate-asymmetry results concern different Stim channels and should remain a separate line of evidence. They do not supply the missing variance or power information for either route.
