# Stage 5 Confirmation Candidate

This directory contains a prospective, no-sampling candidate plan based on the Stage 4C development decision. It is **not authorization to execute**.

- `FROZEN_PROFILE_ESTIMATOR.json` contains compact detector-profile parameters only; no detector shots or observables.
- `seed_inventory.json` and `seed_audit.json` were generated by `prepare_stage5.py`; the audit found 1,002 unique proposed seeds with zero collisions among 3,811 recoverable historical development seed values.
- `STAGE5_CANDIDATE_FREEZE.json` hashes the candidate plan inputs. It does not freeze a future runner or authorize sampling.
- `VERIFY_CANDIDATE_FREEZE.py` checks those hashes and allocation totals without reading sample arrays.

Reproduce the preparation from the repository root:

```powershell
python -m outputs.stage5_independent_confirmation.prepare_stage5
python -m outputs.stage5_independent_confirmation.BUILD_CANDIDATE_FREEZE
python -m outputs.stage5_independent_confirmation.VERIFY_CANDIDATE_FREEZE
```

The plan remains pending independent review of power assumptions, statistical code, and the estimator's copied-parameter provenance. No Stage 5 runner exists, no Stage 5 samples were generated, and no sealed independent-test path or sample was opened.
