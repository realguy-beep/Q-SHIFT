# Unresolved blockers after deterministic implementation

1. **No production runner.** There is no Stim sampler, scientific run controller, decoder construction/scoring orchestration for actual generated samples, or authorization token in this package. The permanent `sampling_guard` rejects activation.
2. **No production seed allocation or collision screen.** The template has no numeric values. Historical collision coverage remains not performed/unknown until a separately approved, explicitly allowlisted metadata audit is conducted.
3. **Resource feasibility unknown.** No sampling, end-to-end benchmark, memory/disk measurement, resume trial using real allocated partitions, or throughput measurement was performed. V2's 1,800 s / 2 GiB RSS / 1 GiB reserve remain proposed limits.
4. **Evidence/provenance limits.** Content digests verify bytes but cannot establish upstream generation provenance, authorization, label non-leakage, or absence of influence from the previously disclosed historical exposure.
5. **Small-root inference limits.** Ten evaluation roots per condition limit bootstrap coverage under skew/zero inflation. Sign-flip validity requires independent clusters and root-level symmetry; its output remains sensitivity-only.
6. **Finite-grid baseline.** The fixed comparator is the selection-partition winner among the six DEM × two mode grid only; bootstrap rank instability may be substantial. The primary interval is conditional on the selected candidate.
7. **No independent physical or accuracy validation.** Deterministic fixtures validate software contracts only. They do not establish decoder accuracy, superiority, physical fidelity, or hardware behavior.

The statistical addendum resolves only the decisions listed there. It does not authorize a freeze, sampling, or progression to NS-4B.
