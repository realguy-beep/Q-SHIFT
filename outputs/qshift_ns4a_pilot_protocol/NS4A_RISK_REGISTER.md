# NS-4A Risk Register

| ID | Risk | Evidence / consequence | Mitigation before a future authorization | Stop condition |
|---|---|---|---|---|
| R1 | BM detector-support/logical-signature alias collision | NS-3B documented that upstream 0.2.0 can overwrite conflicting logical signatures for identical detector support; guard rejects affected DEMs | Run unchanged guard on every predeclared DEM candidate and circuit/condition; retain logs and hashes | Any predeclared DEM rejected or guard semantics cannot be verified |
| R2 | Approximate DEM semantics | NS-2D requires decomposed DEM with `approximate_disjoint_errors=True`; categorical disjoint channels can be approximated during conversion | Use identical DEM bytes/settings/weights for BM and matched PM; disclose approximation | Different DEMs or conversion flags across primary pair, or undefined semantics |
| R3 | Baseline model-selection noise | Eight configs selected from finite independent calibration roots; winner can be unstable | Equal-weight selection objective; disclose all candidates, deterministic ties, root-bootstrap rank frequencies | Selection code uses evaluation labels or cannot reproduce frozen choice |
| R4 | Sparse root count / rare failures | Ten eval roots per condition and 4,000 shots/root may yield few errors or zero cells | Root-level intervals and discordances; no shot-level independence claim; report zero counts without smoothing | Root/seed failures reduce the predeclared design without a reviewed amendment |
| R5 | Bootstrap/sign-flip assumptions | 10 clusters per condition is small; root differences can be skewed, tied, or zero-inflated | Show root values and leave-one-root-out; label sign-flip assumptions; descriptive interpretation only | Invalid or non-reproducible inference implementation |
| R6 | Model-information mismatch | BM and PM can accidentally receive different DEM/provenance despite same detector rows | Freeze and hash same selected DEM/model record for primary pair; compare identity records before each decode | Any identity/provenance mismatch |
| R7 | Sampling/decoder-label leakage | Selection labels are allowed only in selection; evaluation labels score only | Detector-only decoder API; labels stored outside decoder call objects; test using mocks/spies and source audit | Any constructor/decode call can read evaluation labels or condition state |
| R8 | Generator scope confusion | Phase 2B bias changes Pauli composition but holds measurement p; no data-heavy or measurement-heavy channel in inspected generator | Describe balanced/X-/Z-biased accurately; restrict pilot to supported regimes | Report labels a bias condition as data- or measurement-heavy |
| R9 | Synthetic burst interpretation | Phase3A inserts X8X10 at each MR; independent across rounds, no calibrated device physics | Call it a synthetic spatial common-cause proxy; do not claim crosstalk validation | Device-specific or temporal-persistence claim based on this model |
| R10 | Held-out parameter overinterpretation | p=0.005/0.015 are only held out relative to this proposed selection design | Report finite sensitivity at these exact values; no population-generalization claim | Post-hoc selection or tuning using those evaluation conditions |
| R11 | Prediction identity ambiguity | All arms must decode same sample order; hidden input mutation or reordering would invalidate pairing | Immutable/copy-checked `DetectorBatch`, array hashes, output shape/order checks and independent rescoring | Any mismatch, aliasing, mutation, missing prediction or untraceable output |
| R12 | Historical seed coverage incomplete | Recoverable artifacts may not record every historical random stream | Screen only allowed metadata, list files/values and state coverage gaps; generate seeds only after review | Actual collision or inability to separate new allocation from protected namespace |
| R13 | Runtime/RSS uncertainty | Existing data are five-row timing fixtures; native memory/end-to-end Stim not benchmarked | Separate authorized disposable benchmark; 30-minute / 2-GiB stop cap; reserve 1 GiB disk | Cap projection fails or live measurement approaches cap without safe checkpoint |
| R14 | “Strongest” overclaim | Selected baseline is best only over eight predeclared candidates and selection set | Use “selection-best pooled fixed configuration in this grid”; disclose candidates and stability | Claim global/optimal strongest decoder |
| R15 | Adaptive claim drift | NS-4A is fixed BM versus fixed PM; no estimator or switching policy | State that this is decoder feasibility only | Any claim of adaptive performance or noise-estimator benefit |
