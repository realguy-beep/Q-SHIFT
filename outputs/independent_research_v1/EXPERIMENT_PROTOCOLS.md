## Candidate protocol: native categorical inference feasibility

**Status: proposed, not run.** The exact-DEM correlation mechanism protocol is blocked for the categorical two-qubit circuit. A replacement should not simulate a fictitious exact DEM. The existing `outputs/categorical_decoder_feasibility/` has an exhaustive exact reference for tiny categorical models and reports 209 categorical fault locations (2^609 complete assignments) for the Phase 2B distance-3 circuit.

A useful next prototype would build a factor graph directly from mutually exclusive local Pauli outcomes and parity effects on a reduced circuit fragment, then compare exact variable elimination or tensor contraction with exhaustive categorical enumeration on a toy and a bounded fragment. Before coding, define a fragment with explicit detector/observable boundary conditions and verify its native-channel distribution against deterministic forced-outcome Stim enumeration. Advance only if the inference exactly matches brute force on multiple small fragments, with a recorded maximum intermediate factor size and memory/time. No full-circuit performance inference follows from fragment agreement.

No sampling, final evaluation, or Phase 2B pilot-data reuse is part of this feasibility protocol. If exact variable elimination has prohibitive induced width on the fragment, stop and report the measured width and cost. Do not replace it with a posterior surrogate without a separate approximation validation plan.

## Completed deterministic approximation-threshold preflight

The scan in `dem_threshold_scan.py` tried the prospectively chosen threshold values 0.001, 0.0018, 0.003, and 1.0 for each Phase 2B basis/regime circuit. It only builds DEMs and PyMatching graphs and compares hashes. It generates no detector samples. Results are saved in `approximation_threshold_scan.json`. The scan found one valid DEM per condition across all successful thresholds, so a sampled threshold-sensitivity decoder comparison is not justified at the current configured probability vector.

## Tensor-network MPS feasibility screen

**Status: stopped at preflight; full screen not run.** Compare qecsim's planar Matrix Product State (MPS) decoder (`chi=None`, contraction mode `c`) against qecsim's planar MWPM decoder on identical physical errors. Use `PlanarCode(d,d)` at d=3 and d=5, qecsim's IID depolarizing code-capacity error model at p=0.05, and 5,000 paired error samples per distance. Primary descriptive endpoint is paired LER difference MPS minus MWPM at d=3. d=5 is a scaling check. Report per-arm LER, paired-only failures, exact two-sided McNemar test on discordant samples, paired mean-difference normal interval, runtime per decode and peak process RSS. Verify each recovery returns to the stabilizer codespace.

The run uses Python `numpy.random.default_rng` seeds 202611181 (d=3) and 202611182 (d=5). The fixed sample count and noise strength are not tuned after inspecting outcomes. A separate 100-shot preflight uses seeds 202611183 and 202611184. Abort the full run if the preflight extrapolates above five minutes total, if either decoder returns an invalid recovery, or if the error generator/noise settings differ from the declared model. This is a code-capacity decoder feasibility experiment with perfect syndrome extraction. It does not estimate Q-SHIFT circuit-level performance, include measurement noise, or authorize integration. The preflight runtime projected the 5,000-shot run slightly above five minutes, so the prospective stop rule was applied; the preflight failure counts are not used as comparative performance evidence. A separate bounded-bond MPS study would require a new protocol, fresh samples, and a preflight before any performance interpretation.

## Candidate protocol: BP+LSD on the Phase 2B circuit model

**Status: predeclared development screen.** Compare the current strong baseline (PyMatching created from the Phase 2B approximate DEM with correlations enabled) with LDPC 2.4.1 `BpLsdDecoder` on identical detector/observable samples generated by the original Phase 2B circuits. Evaluate the six memory-basis/regime conditions, 5,000 shots each. The decoder-facing DEM uses `decompose_errors=True` and `approximate_disjoint_errors=0.0018`, which passed the deterministic conversion scan and produced the same DEM as the other tested successful thresholds. The outcome sampler remains the original circuit, so this explicitly measures decoder sensitivity to the approximate DEM representation.

Build binary matrix H (detectors × flattened DEM error instructions) and logical matrix L (observables × fault instructions), XORing repeated targets per instruction. Use one binary fault variable per DEM instruction with its stated probability. Compare three fixed LSD variants (`LSD_0`, `LSD_E`, `LSD_CS`), all using min-sum BP, scale 0.9, max_iter 200, LSD order 0, bits_per_step 1, and library defaults for other controls. Decode each observed detector vector; predict observables as L times the returned fault vector modulo 2. Verify output dimensions and decoder determinism on a repeated fixed syndrome before sampling.

Use one independent 100-shot-per-condition runtime/validity preflight with seeds 202611201 through 202611206, excluded from all performance summaries. Use main development seeds 202611191 through 202611196 in the fixed order x-biased, balanced, z-biased for z-memory, then the same order for x-memory. Stop without full sampling if preflight projects above five minutes total or any decoder fails the deterministic validity gate. Primary descriptive metric is paired LER difference versus correlation-enabled PyMatching for each LSD variant, reported by condition and macro-averaged equally over the six conditions. Report discordant counts, Wilson intervals, paired intervals, runtime, peak RSS, and per-condition results. This is a single development comparison under the existing approximate-DEM mechanism; it is not confirmatory and does not authorize integration or a superiority claim.

## Candidate protocol: likelihood-ratio importance sampling on the DEM surrogate

**Status: deterministic estimator validation plus conditional preflight.** The objective is to test whether rare-event sampling can reduce variance when estimating the fixed correlation-enabled PyMatching LER under the *approximate DEM surrogate*. It does not estimate the original categorical circuit distribution. Build each of the six distance-3 Phase 2B DEMs at the already screened threshold 0.0018. Validate the importance weights by exhaustive enumeration of every fault pattern in a tiny three-event DEM, checking both total probability and exact decoder-failure expectation under the target distribution.

Compare ordinary DEM sampling at original event probabilities p with independent proposal sampling after a uniform fivefold odds tilt q=5p/(1-p+5p). Use event-vector outputs from `CompiledDemSampler` and the exact product Bernoulli likelihood ratio. Decode both arms using the same fixed correlation-enabled PyMatching built from the original p DEM. The preflight uses 5,000 samples per condition per arm, with direct seeds 202611211–202611216 and tilted seeds 202611221–202611226. It is only an efficiency preflight. Advance to a separate 20,000-per-condition development comparison only if importance sampling reduces estimated relative standard error by at least 25% in at least four conditions, weighted estimates remain finite, and no support/weighting validation fails. Otherwise stop this candidate. If advanced, use new direct seeds 202611231–202611236 and tilted seeds 202611241–202611246. Report weighted LER, empirical standard error, failure-weight effective sample size, max absolute log weight, direct LER, and runtime. All samples are from the explicitly approximate DEM; no circuit-level rare-event estimate or confirmatory conclusion follows.

Because the first two independent screens showed variance reduction, a replication follow-up is predeclared to challenge stability: run eight independent replicates of 5,000 samples per arm per condition, with direct seeds 202611301–202611348 and tilted seeds 202611401–202611448, in six-condition blocks. Compare between-replicate standard deviations of the direct and importance estimates by condition and report mean paired-replicate estimator differences with uncertainty. This follow-up tests estimator stability and bias only for the same DEM surrogate and fixed decoder; it does not constitute a circuit-level claim.

## Candidate protocol: exact categorical circuit importance sampling

**Status: instrumented-channel validity gate, followed by a bounded development screen.** Test whether each original `PAULI_CHANNEL_2` pair can be replaced by an exact mutually exclusive chain of `CORRELATED_ERROR` / `ELSE_CORRELATED_ERROR` branches, with a private four-bit flag register encoding the sampled Pauli pair. Keep all original detector/observable measurements in place; append flag measurements at circuit end and expose them only as extra observables. The direct instrumented circuit uses the original probabilities. The proposal multiplies each nonidentity Pauli-pair probability by five relative to identity and renormalizes the 16 categorical outcomes. One flag quartet is allocated per independent two-qubit channel pair. Weight each tilted shot by the exact product categorical ratio over those pair locations; one-qubit and measurement channels are unchanged and cancel from the ratio.

Before Q-SHIFT sampling, validate the replacement on a synthetic two-qubit channel with known probabilities. Confirm flag codes, all 15 data Pauli actions, direct frequencies, tilted frequencies, and equality of original detector/observable behavior on a noiseless Clifford fixture. Abort if any flag code is invalid, the number of base detectors/logical observables changes, any original measurement reference shifts, or the measured categorical frequencies fail the fixed binomial tolerance. Then run a 200-shot-per-condition timing/validity preflight on the six exact Phase 2B circuit conditions. If it stays within five minutes total and produces finite weights/support, run 20,000 direct and 20,000 tilted circuit samples per condition. Preflight seeds: direct 202611501–506, tilted 202611507–512. Main seeds: direct 202611521–526, tilted 202611531–536. Keep decoder fixed to correlation-enabled PyMatching from the original approximate DEM; the target is its LER under the exact source circuit distribution. Report direct LER, weighted LER, empirical standard error, failure-weight ESS, max absolute log weight, runtime, and all condition-level outcomes. This is a development estimate, not a 99.99% claim or confirmatory result.

Because the exact-categorical screen is promising, test stability with eight independent 5,000-per-arm replicates using new seed blocks: direct 202611601–202611648, tilted 202611701–202611748. Report between-replicate SD ratios by condition and mean importance-minus-direct estimate with standard error. This is a robustness check of the same fixed proposal and decoder, not tuning or confirmation.

**Stability amendment:** the first replication block had an importance/direct between-replicate SD ratio above 1 in one condition. To distinguish a repeatable stratum-specific problem from a single unstable block, run a second independent eight-replicate block at the same fixed settings and shot count, with direct seeds 202611801–202611848 and tilted seeds 202611901–202611948. Do not change the tilt factor or decoder. Report each block separately and combined; no parameter selection is made from these outcomes.

**Instrumentation check:** independently sample each unmodified source Stim circuit for 20,000 shots per condition using seeds 202611551–202611556. Decode with the same fixed correlation-enabled PyMatching. Compare these direct rates with the instrumented alpha=1 direct arm; report their standardized differences using independent-binomial standard errors. Require every absolute z difference to remain below 4 before treating the categorical flag instrumentation as validated for the source circuits. This validation uses fresh original-circuit samples and does not use the tilted arm.
