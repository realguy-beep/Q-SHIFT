# Focused prior-work comparison

This review focuses on the three candidate directions. It is a direction-selection review, not an exhaustive systematic review. Peer-reviewed results are distinguished from software documentation and a very recent preprint.

| Work | What it establishes | Relevance to Q-SHIFT | Boundary / limitation |
|---|---|---|---|
| Dennis, Kitaev, Landahl & Preskill, “Topological quantum memory,” *J. Math. Phys.* 43, 4452–4505 (2002), [doi:10.1063/1.1499754](https://doi.org/10.1063/1.1499754) | Surface-code memory has a threshold transition; below threshold, larger blocks can suppress logical failure under stated locality/model assumptions. | Direction C’s distance/noise operating map is important and teachable. | A generic finite-distance sweep in Stim is not a new threshold theorem or a hardware threshold measurement. |
| Gidney, “Stim: a fast stabilizer circuit simulator,” *Quantum* 5, 497 (2021), [doi:10.22331/q-2021-07-06-497](https://doi.org/10.22331/q-2021-07-06-497) | Describes stabilizer and Pauli-frame simulation methods and high-throughput circuit sampling. | Supports the simulation infrastructure. | Does not establish that a converted DEM preserves the full categorical circuit distribution or decoder decisions. |
| Stim DEM and CLI documentation, [DEM format](https://github.com/quantumlib/Stim/blob/main/doc/file_format_dem_detector_error_model.md), [`approximate_disjoint_errors`](https://github.com/quantumlib/Stim/blob/main/doc/usage_command_line.md) | DEM instructions represent independent error mechanisms; some custom Pauli channels need explicit approximation; decomposition suggestions make graphlike decoding possible. | Defines Direction A’s exact representation question and an important limitation of the Phase 2B noise-to-DEM path. | Documentation defines software semantics, not the size of LER impact for Q-SHIFT’s circuits. |
| Higgott et al., “Improved decoding of circuit noise and fragile boundaries of tailored surface codes,” *Phys. Rev. X* 13, 031007 (2023), [doi:10.1103/PhysRevX.13.031007](https://doi.org/10.1103/PhysRevX.13.031007) | Belief-matching/belief-find leverage circuit-level correlations and outperform ordinary MWPM for studied models; reports a 0.940(3)% vs 0.817(5)% threshold for its circuit-level depolarizing comparison. | Establishes that correlations and hyperedges can matter; relevant to B and to biased-noise context. | Different decoder, code/model and threshold study; those values are not predictions for this project. |
| Paler & Fowler, “Pipelined correlated minimum weight perfect matching of the surface code,” *Quantum* 7, 1205 (2023), [doi:10.22331/q-2023-12-12-1205](https://doi.org/10.22331/q-2023-12-12-1205) | Studies correlated graph reweighting and a pipeline for rotated, unrotated and toric codes under standard depolarizing circuit noise. | Confirms correlated matching and its latency motivation predate Q-SHIFT. | It is not the same as PyMatching’s two-pass API; the study’s noise and pipeline architecture differ. |
| PyMatching 2 correlated matching, [official PyPI documentation](https://pypi.org/project/PyMatching/) | Since v2.3, provides a two-pass sparse-blossom correlated matching option; documentation describes when decomposed hyperedges yield useful correlation information. | Installed version 2.4.0 supports a low-cost same-DEM on/off ablation. | A software capability is not evidence of gain on every model; the current Q-SHIFT run enabled the feature throughout and lacks a direct ablation. |
| Google Quantum AI, “Quantum error correction below the surface code threshold,” *Nature* 638, 920 (2025), [doi:10.1038/s41586-024-08449-y](https://doi.org/10.1038/s41586-024-08449-y) | Demonstrates distance-dependent logical suppression in hardware and discusses sensitivity to error sources and rare correlated events. | Gives context for Direction C and motivates transparent model limitations. | Hardware results cannot be numerically compared with the project’s idealized Stim noise model. |
| de la Fuente et al., “Correlated decoding loses the surface code’s effective distance below threshold,” arXiv:2610.26785 (posted October 2026), [arXiv](https://arxiv.org/abs/2610.26785) | Reports that a standard correlation-reweighting rule can over-discount correlated edges in certain low-noise failure configurations and studies regularization. | A recent caution that correlation-aware decoding should be measured rather than presumed superior. | New preprint, not peer-reviewed consensus; its specific matching/clustering reweighting rule should not be assumed equivalent to PyMatching’s two-pass implementation. |

## Literature conclusions

1. **Direction A:** The approximation is real and documented, but the project has not isolated how much it changes LER. Existing learned-reference evidence is too weak to attribute utility loss to DEM construction.
2. **Direction B:** Correlation-aware decoding is established and has shown gains in other settings. Q-SHIFT’s contribution would be a controlled ablation in its own explicitly specified channels, not a new correlation-decoding method.
3. **Direction C:** Distance scaling and threshold behavior are established core science. A classroom-quality, reproducible sensitivity study is achievable, but novelty would be modest absent a narrowly new model or regime.

No publication novelty claim is made. The competition value here is a careful experiment that distinguishes model fitting from decoder algorithm behavior and preserves negative results.
