## Independent results

All arms used the same evaluation detectors in each block. C1 compares W0F with its delayed overlay and therefore measures the value of access to **current** detector calibration under the stipulated one-block latency. C2/C3 give their comparison arms the same overlay, samples and latency. LA_STATIC is an overlay on training-selected A, so it can switch. C2 does not establish superiority to the strongest fixed or delayed decoder. LA_DB2 in fact has fewer errors on AB and BB. ORACLE receives block truth. Its results describe an information-advantaged reference, and its error count is not a decoder limit.

The base uses only previous block history, including **labeled** calibration. The overlay uses current detector-only counts and the preceding segment, before evaluation sampling/scoring. It does not carry its chosen key into base state. Prior truth passed to the estimator feeds correctness diagnostics at the inspected call sites. All 1,152 recorded overlay decisions follow the alarm and singleton rule, including fallback to each arm's base. This supports causal use under the delayed contract. The simulation assumes a shared block-constant state for separately generated calibration and evaluation batches. See v6 `db6_run.py:90–114,141–190`, `db6_core.py:14–28`, `db6_config.py:32–36`; `outputs/qshift_adaptive_robust_v1/brt.py:64–77`.
