# Q-SHIFT evidence inventory

## Scope and audit method

This audit reads archived result files, frozen configurations, saved prediction/observable arrays, selected decoder records, and historical manifests. It generates no circuit shots and changes no historical experiment. `audit_existing_headroom.py` independently recalculates residual logical errors from saved prediction/observable pairs, reselects models only from saved calibration arrays where those arrays exist, and records complementary-error counts. It inspected 802 archived NPZ evidence bundles for the calculations in `RESULTS.json`; this count is a file count, not a count of independent experiments. Independent prior decoder re-decoding audits are cited where applicable.

The evidence is separated by its actual status. A report or manifest is not treated as equivalent to saved raw predictions. “Confirmatory” below means a protocol-defined untouched test within that study, not confirmation of the overall adaptive hypothesis.

## Provenance and manifest status

`verify_archived_manifests.py` scanned 30 JSON manifests and checked 2,233 file-hash entries. Twenty-eight manifests pass completely. The original Phase 4A manifest has exactly three Markdown hash/size mismatches; the independently created `MANIFEST_FINAL.json` matches all 226 of its entries. The old Phase 4A discrepancy is documented in `outputs/phase4a_integrity_reaudit/`. The Phase 5 adaptive manifest is stale for six of its 13 source/report entries after subsequent corrections; current hashes are preserved in this audit, while the Phase 5 result files are not silently rewritten. See `MANIFEST_VERIFICATION.md` and `.json` for every entry.

The workspace has no Git metadata, so Git history cannot establish chronology. Protocol files and recorded freeze hashes provide evidence of intended pre-test decisions, but file timestamps or a later manifest do not prove that a protocol was cryptographically frozen before test access. The Phase 4A independent audit passed scientific artifact recomputation while separately noting that chronology is not provable from Git.

## Evidence categories

- **Raw paired predictions and labels:** phases 2A, 2B, 2C, 4A, 4B, 4C Stage 2, correlation pilot, headroom feasibility, prototype development, and uncertainty-gate development.
- **Raw detectors/labels but no predictions:** Phase 3B. This audit therefore reports saved summaries and does not claim an independent prediction recomputation.
- **Summary-only dynamic evaluation:** Phase 5D/5E; Phase 5E seed-derived sample counts can be reconciled from its saved runner/config, but shot arrays are absent.
- **Incomplete model-selection provenance:** Phase 4C Stage 2, because calibration detector arrays are absent even though test predictions were independently re-decoded.
- **Deterministic exact/model checks:** categorical and representation studies. These are not stochastic test samples and are not pooled with surface-code LER estimates.
