# Competing explanations for the basis–bias pattern

The current evidence supports an observed interaction in this distance-3 simulation. It does **not** establish any of the mechanisms below. “Evidence” separates what the saved files show from interpretation.

| Hypothesis | Current evidence consistent with it | Evidence against / missing | Discriminating test |
|---|---|---|---|
| **H1. Basis and Pauli composition alter which decomposed fault correlations lead to the logical observable.** | Same-name cells have higher residual LER with correlation mode enabled; the four other cells favor it. X/Z memory circuits have different detector-coordinate layouts and different DEM topologies (564 vs 572 separators). | Only two post-hoc adverse cells; no latent Pauli fault history or matching-path attribution. “Same-name” is a label relationship, not proof that the bias is aligned with the logical error operator. | Repeat the six-cell factorial with fresh roots and a second validated DEM representation; collect fault-event/path diagnostics where possible. Confirm whether the interaction persists in the less approximated representation. |
| **H2. Correlation-enabled matching changes a small set of correction decisions; these corrections can help or harm.** | Off/on use the same DEM, graph weights, detector IDs, observable IDs, and paired samples. Predictions differ on 1,343 shots; 763 changes favor on and 580 favor off. | The internal matching decomposition/path is not saved, so no named algorithmic operation can be assigned. | Instrument a decoder/reference implementation to log candidate corrections and correlation metadata; match cases on the same detector syndrome. |
| **H3. Disjoint-error approximation creates or amplifies the pattern.** | All arms use `approximate_disjoint_errors=True`; the true circuit samples mutually exclusive categorical Pauli events. Correlated matching can only use metadata surviving the approximate DEM conversion. | Within each basis the number/topology of separator records is constant across noise regimes. This does not rule out probability-weight changes interacting with the approximation. No alternative DEM arm was tested. | Compare correlation on/off under the same circuits with a validated non-approximated disjoint-error conversion. Stop if Stim cannot construct a semantically valid matching model without approximation. |
| **H4. Pooled decoder-model mismatch creates the harm.** | Four non-same-name cells compare a pooled basis-selected model against generating conditions with different Pauli mixtures; correlation may change the mismatch penalty. | The two harmful same-name cells have pooled index equal to regime index, and pooled/regime-informed predictions are exactly identical. Pooled-versus-regime mismatch is therefore not necessary for the harm. The shared DEM can still mismatch the native categorical channel. | Evaluate pooled and regime-informed models under each DEM representation using calibration-selected pooled models, and separate the on/off contrast within each exact model identity. |
| **H5. Distance-3 degeneracy/finite-size behavior drives the interaction.** | The circuit is only distance 3 with five rounds; logical correction decisions are made in a small graph where a few short paths can dominate. | No distance comparison exists in this pilot. | A later distance-5 replication under the same frozen noise factorial, after the distance-3 approximation question is resolved. |
| **H6. The post-hoc pattern is a selection or sampling artifact.** | Six cells were inspected; the same-name grouping was emphasized after the outcomes were seen; only 12 root clusters/cell. | Root direction is fairly consistent within each cell (9/12 and 11/12 harmed in the two adverse cells; 8–12/12 helped in the others). This is suggestive, not independent confirmation. | Freeze the interaction and direction before a fresh test, with adequate root clusters and paired-discordance-based power. |

## Current ranking

H2 is the only explanation directly supported at the implementation level: toggling correlation behavior on the same approximate DEM changes the decoded observable for a small subset of detector samples. H1 is a plausible description of the condition-level pattern, but the physical mechanism is unobserved. H3 and H5 remain unresolved. H4 alone is insufficient to explain the same-name harm. H6 cannot be dismissed until independent replication.

No neural or adaptive selector is justified by this evidence. The immediate next scientific step is a frozen test that separates the correlation algorithm's utility from the DEM's disjoint-channel approximation.
