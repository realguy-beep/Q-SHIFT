# Q-SHIFT experiment index

This index points to preserved local evidence; it does not replace the per-study protocol or audit. `outputs/` is intentionally not ignored wholesale. Raw NPZ/NPY shot bundles, model checkpoints, local run directories, logs and sensitive files are excluded from Git but remain on this machine. All listed statuses are evidence-specific; studies with different circuits or estimands must not be pooled without a justified analysis.

python -m unittest discover -s dashboard\tests -v
python dashboard\verify_structured_resume.py
python dashboard\audit_structured_development.py outputs\neural_decoder_diagnostic\structured_integration\dev_run_6000

The saved structured development run used 6,000 training and 3,000 validation shots. Direct/pooled models collapsed at selected thresholds; the residual MLP copied PyMatching; the position-preserving model remained worse than PyMatching. These are development findings, not independent test results.

## Index maintenance

When a new milestone is complete, add its directory, frozen status, seed-manifest path, integrity-manifest path/hash, and safe reproduction/audit command. Keep new raw arrays and checkpoints local. Do not change a historical row to hide a failed or superseded result.
